# Sobre o projeto

- Projeto desenvolvido para a disciplina Programação Avançada Para Dispositivos Móveis da UFABC. Para a conclusão da disciplina, foi necessário o desenvolvimento de um projeto de cunho social.
- O EcoFinder visa encontrar ecopontos na cidade de Santo André e São Bernardo do Campo próximos ao usuário, para auxiliar no descarte de objetos e materiais
- Vídeo demonstrativo: https://www.youtube.com/watch?v=Gcwj14Ha5S0
